# VantaGrid project rules

- Keep this repository, its deployment, brand assets, data configuration, and documentation scoped to VantaGrid.
- Do not import another product's brand, favicon, repository, hosting project, or database configuration.
- Keep copy specific to Small-business cybersecurity; make no unsupported claims about outcomes or integrations.
- Keep the interface distinctive, responsive, and lightweight; use transform/opacity animation and respect reduced-motion preferences.
- Keep the hero headline concise and public-facing content focused on the service.
- Verify build output and the public URL before reporting a release.
